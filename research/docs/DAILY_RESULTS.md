# DAILY_RESULTS — H3 daily candle-2 closure (DAILY_SPEC v1), TRAIN and VALIDATION only

Status: the sealed TEST segment has NOT been run or looked at. `scripts/run_daily.py --segment test` refuses unless a freeze record exists
(`final_test_guard`), and requires a single `--variant`. Nothing was tuned; rules, costs and sizing are exactly DAILY_SPEC v1
(`configs/daily_strategy.yaml`, `configs/daily_costs.yaml`). Tables are generated by the script (`results/daily/*_report.md`) and copied here unedited.

Reproduce: `cd research && python -m pytest tests/test_daily_*.py -q && python scripts/run_daily.py --segment train && python scripts/run_daily.py --segment validation`

## Setup actually used
- Data: SPY/QQQ/IWM daily (data/processed, real IBKR connector bars). Split via `make_split` on the common span, 60/20/20, purge 3 calendar days; trades assigned by entry time (`apply_split`). Train = 2022-10-12..2025-03-04, validation = 2025-03-04..2025-12-20 (purge 3 days after each boundary; see `results/daily/validation_summary.json` -> split).
- ATR14 = simple mean of the last 14 true ranges on H*,L*,close through day t (spec does not say Wilder vs simple; simple chosen). Signals need ATR to exist (first 14 bars of each series have none, so no signal) and t-1 to exist. Used for R only; there is no stop.
- Sizing $10,000 notional, fractional shares. Costs per round trip: 2 x $0.35 commission + 2 x $0.005/share + 1 bp (open) + 0.5 bp (close) of notional (ASSUMPTIONS, unverified). Because notional is $10,000, 1 bp == $1, so "EV bps" equals "EV $" numerically.
- Cost x1.5 / x2 rows re-price `pnl_gross - m*costs` via `montecarlo.cost_stress`.
- Pooled-by-date = all three symbols' trades in one table; the bootstrap/t-test cluster by NY entry date. Per-symbol rows use the same cluster logic on the subset.
- "days in mkt" = distinct entry dates with a trade / distinct candidate entry dates in the segment (any symbol).
- B_D1 draws are independent per instrument (as the spec says), while real signals are correlated across the three ETFs on the same date, so the null is somewhat narrower than a date-matched null would be; this flatters the strategy slightly, it does not hurt it.
- Multiple testing: N = 16 registered variants overall (13 intraday + 3 daily). Bonferroni p = min(1, 16 x day-clustered two-sided p). DSR from `stats.deflated_sharpe` on the daily net-P&L series of days that have a trade (T = those days), N = 16, cross-trial Sharpe variance approximated as 1/(T-1) (i.e. assumes variants are exchangeable noise; understates the haircut if variants truly differ; days without trades are excluded; iid assumed). Treat DSR as a rough screen.
- Monte Carlo: `day_block`, 5000 paths, seed 20261008, account base $10,000 (only drawdown in USD is used). It resamples the same evidence and adds no independent market evidence.
- Bootstrap seed 20261008 (5000 resamples), B_D1 seed 20261008 (10,000 draws).

## Sample size, plainly
Pooled signal counts are larger than the "~100" the spec expected (V1: 471 train + 152 validation trades) because the three ETFs fire on separate days, but the trades are strongly dependent across symbols on shared days and the validation slice is 200 trading days (about 9.5 months, 4 partial quarters, one market regime). Per-symbol validation n is 20-57 (long-only and short-only: 20-30 per symbol). Day-block 95% CIs of validation EV are about +/- $30-50 per trade, i.e. much wider than any plausible edge net of cost (the cost itself is ~$2.5 per trade). Nothing below is evidence of an edge; quarterly sign flips and 5+x top-trade concentration are what noise looks like at this n.

## Interpretation (descriptive, no tuning)
- V1 (primary, both sides): train net EV -$5.32/trade (-0.033 R), validation +$1.91/trade (+0.009 R); both CIs straddle zero (validation [-26.6, 29.5]); EV at x2 costs on validation is -$0.57. B_D1 percentile 0.25 (train) and 0.66 (validation): indistinguishable from random days. Verdict REJECTED by the pre-registered rule "train net EV <= 0 at 1.0x costs with n >= 30" (train n = 471). Note the rejection comes from the train segment; the validation point estimate alone is slightly positive but statistically nil.
- V2 (long-only): negative on train (-$18.4/trade, CI excludes 0 on the low side, B_D1 percentile 0.001) and on validation (-$4.8). REJECTED. Bullish C2 longs lose even relative to random long days.
- V3 (short-only): the only positive variant: train +$7.84 (B_D1 p = 0.022), validation +$8.57 (B_D1 p = 0.082, percentile 0.918). Validation CI [-43.4, 53.5]; it does not beat the 95th percentile of random shorts on validation; Bonferroni p = 1.0; DSR 0.07; the P&L is concentrated in one quarter (2025Q4: +$2,253 against -$2,156 in Q2+Q3), and single symbols flip sign (SPY shorts -$26.85/trade, QQQ/IWM positive). Verdict INCONCLUSIVE (fails the sample gate n_val >= 100 [76], CI, Bonferroni, DSR, quarter consistency, concentration and baseline gates). A short signal's positive train EV partly reflects that the random-SHORT null is negative (drift is up, null mean about -$3 to -$10), so beating B_D0 is not the bar; beating random shorts is, and it only does so in train.
- Short-vs-long asymmetry is reported for description only; splitting into V2/V3 after seeing results would be a new hypothesis, not allowed here. It is already in the registered variants, so no extra tests were added.
- Verdict gates are those in `validation/verdict.py`; none were changed. Because the verdict function requires `max_period_share`, we pass the largest single-month share of total net P&L (can exceed 1 when other months lose; None when total <= 0, which fails).

## Leakage / correctness checks performed
- Unit tests: truncating or garbling all prices after day t leaves H*, L*, ATR14 and the raw signal at <= t unchanged; hand-computed long and short trade (qty, gross, costs, net, R, timestamps) to 1e-9; envelope repair; outside-day, close-outside-range, >4-day gap, warm-up and last-bar cases; 3 symbols on one day cluster to one day; determinism by seed; float qty accepted by `stats.metrics`, `montecarlo.run_montecarlo`, `montecarlo.cost_stress`.
- Independent loop re-implementation of the signal rule and gross P&L over the full real series for each symbol: signal counts and side/entry/gross P&L matched exactly (SPY 253, QQQ 248, IWM 284 total signals across the whole span; no segment returns beyond train/validation were viewed or printed).
- No result looked too good, so no leakage hunt beyond the above was triggered.

## Remaining caveats
- Half-day sessions: exit_ts is fixed at 16:00 New York, close bar values are as delivered; early-close days (about 3 per year) are not special-cased.
- SEC/FINRA fees, CAD/USD FX conversion, dividends, borrow/short availability are not modelled. Short-selling ETFs through IBKR Canada has not been verified.
- 15-minute delayed "Last" prices; open/close prints may differ from auction prices actually obtainable.
- The test segment (final ~20%, 2025-12-20 onward) has not been examined. The coordinator must freeze one variant (`python scripts/run_daily.py --freeze <variant>`), then run `--segment test --variant <variant>` once.
